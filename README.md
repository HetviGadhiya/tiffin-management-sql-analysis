# Tiffin Management SQL Analysis

## About the Project
This project is based on a small tiffin order dataset.
I used SQL queries to understand order details,
revenue, ratings and delivery time.

## Database
- Database: tiffin_management
- Table: tiffin_orders
- Total Records: 12

## SQL Concepts Used
- SELECT
- WHERE
- UPDATE
- COUNT()
- SUM()
- AVG()
- MIN() and MAX()
- COALESCE()
- ROUND()
- NULL value handling
- BETWEEN

## Tasks
1. Handling NULL values in customer ratings.
2. Finding Jain meal orders in February 2026.
3. Updating ratings for late deliveries.
4. Calculating overall business KPIs.

- MySQL / MariaDB
- phpMyAdmin
- XAMPP
